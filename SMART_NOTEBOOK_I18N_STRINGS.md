## 使用说明

### 在代码中使用

```typescript
intl.formatMessage({
    id: 'smart_notebook.uploading_progress',
    defaultMessage: 'Uploading files ({current}/{total})...',
}, {current, total});
```

### 参数说明

- `{current}` - 当前上传进度
- `{total}` - 总文件数
- `{count}` - 失败文件数量
- `{names}` - 失败文件名列表
- `{error}` - 错误信息

### 添加步骤

1. 打开语言文件：
   - 英文：`/assets/base/i18n/en.json`
   - 简中：`/assets/base/i18n/zh-CN.json`
   - 繁中：`/assets/base/i18n/zh-TW.json`

2. 在文件中搜索合适的位置（如 `"smart_notebook.` 开头的字符串附近）

3. 复制上面提供的字符串并添加到文件中

4. 确保 JSON 格式正确（注意逗号）

5. 保存文件并重启应用

## 验证

添加字符串后，可以这样验证：

```bash
# 检查 JSON 格式
node -e "console.log(JSON.parse(require('fs').readFileSync('/assets/base/i18n/zh-CN.json', 'utf8')))"

# 搜索特定字符串
grep "smart_notebook.uploading_progress" /assets/base/i18n/*.json
```

## 注意事项

1. **JSON 格式**：确保添加的字符串符合 JSON 格式
2. **键名一致性**：确保所有语言文件使用相同的键名
3. **参数匹配**：确保翻译中包含相同的参数占位符
4. **测试**：在不同语言下测试所有功能
5. **默认消息**：代码中的 `defaultMessage` 应该是英文

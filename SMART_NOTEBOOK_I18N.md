## 📝 使用示例

### 1. 标题输入对话框

```typescript
// 对话框标题
intl.formatMessage({
    id: 'smart_notebook.enter_title',
    defaultMessage: '请输入标题',
})

// 对话框消息
intl.formatMessage({
    id: 'smart_notebook.enter_title_message',
    defaultMessage: '您的笔记还没有标题，请输入一个标题：',
})

// 取消按钮
intl.formatMessage({
    id: 'smart_notebook.cancel',
    defaultMessage: '取消',
})

// 保存按钮
intl.formatMessage({
    id: 'smart_notebook.save',
    defaultMessage: '保存',
})
```

### 2. 占位符文本


## ⚠️ 注意事项

### 1. JSON 格式

确保 JSON 文件格式正确：
```json
{
  "key1": "value1",
  "key2": "value2"
}
```

**常见错误**：
- ❌ 最后一个键后面有逗号
- ❌ 键名没有引号
- ❌ 使用单引号而不是双引号

### 2. 占位符参数

某些翻译包含参数：
```json
"smart_notebook.uploading_progress": "正在上传文件 ({current}/{total})..."
```

使用时传入参数：
```typescript
intl.formatMessage(
    {
        id: 'smart_notebook.uploading_progress',
        defaultMessage: '正在上传文件 ({current}/{total})...',
    },
    {current: 1, total: 3}
)
```

### 3. 复数形式

如果需要支持复数（例如"1 file"vs"2 files"），使用 ICU 语法：
```json
"smart_notebook.files_count": "{count, plural, =0 {no files} one {# file} other {# files}}"
```

```typescript
intl.formatMessage(
    {
        id: 'smart_notebook.files_count',
        defaultMessage: '{count, plural, =0 {no files} one {# file} other {# files}}',
    },
    {count: 5}
)
// 输出: "5 files"
```

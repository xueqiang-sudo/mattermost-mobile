# 侧边栏频道分类逻辑改造说明

## 目标

将侧边栏频道的"内部群/外部群"分类依据，从 **外部联系人系统（employee_contacts 表）** 改为 **团队成员归属（team membership）**。

### 分类规则

| 频道类型 | 分类条件 | 结果 |
|----------|----------|------|
| Public（公开频道） | 不检查，始终归入内部群 | `internal` |
| 有 `group_channel_category` 偏好且值为 `'internal'` | 按偏好 | `internal` |
| DM（私聊） | 对方用户在当前团队中 | `internal` |
| DM（私聊） | 对方用户**不在**当前团队中 | `external` |
| GM（群聊） | **所有**成员（排除自己）都在当前团队中 | `internal` |
| GM（群聊） | 有任何成员（排除自己）**不在**当前团队中 | `external` |
| Private（私密频道） | 同 GM 规则 | 同上 |
| 其他类型 | 兜底 | `external` |

### 渲染顺序

1. 内部群（internal）
2. 外部群（external）
3. 用户自定义分类（custom categories）— 不参与自动分类

### 频道内排序

每个分类内部：公开频道优先 → 收藏频道次之 → 其余

## 数据来源

分类逻辑依赖的 Redux 数据：

| 数据 | Redux 选择器 | 来源模块 |
|------|-------------|----------|
| 当前团队 ID | `getCurrentTeamId(state)` | `mattermost-redux/selectors/entities/teams` |
| 当前团队成员 | `getMembersInTeam(state, teamId)` → `Record<userId, TeamMembership> \| undefined` | `mattermost-redux/selectors/entities/teams` |
| 当前用户 ID | `getCurrentUserId(state)` | `mattermost-redux/selectors/entities/users` |
| 频道成员 | `getUserIdsInChannels(state)` → `Record<channelId, Set<userId>>` | `mattermost-redux/selectors/entities/users` |
| 所有频道 | `getAllChannels(state)` | `mattermost-redux/selectors/entities/channels` |
| 用户偏好 | `getMyPreferences(state)` | `mattermost-redux/selectors/entities/preferences` |

### 关键：如何构建"当前团队成员 ID 集合"

```typescript
// 在 createSelector 的 input selector 中：
(state: GlobalState) => {
    const teamId = getCurrentTeamId(state);
    const members = getMembersInTeam(state, teamId);
    if (!members) {
        return new Set<string>();
    }
    return new Set(Object.keys(members));
}
// 返回: Set<string> — 当前团队所有成员的 userId 集合
```

用 `Set<string>` 而非 `Record` 是因为 `classifyChannel` 中只需做 `.has()` 查询，Set 语义更清晰。

## classifyChannel 函数

这是核心分类函数，接收单个频道和上下文数据，返回 `'internal'` 或 `'external'`。

### 函数签名

```typescript
function classifyChannel(
    channel: Channel,
    currentUserId: string,
    currentTeamMemberIds: Set<string>,       // 当前团队所有成员 ID
    profilesInChannel: Map<string, Set<string>> | undefined,  // channelId → 成员 ID 集合
    myPreferences: Record<string, any>,
): string
```

### 完整逻辑（伪代码）

```
function classifyChannel(channel, currentUserId, currentTeamMemberIds, profilesInChannel, myPreferences):

    // 规则 1：公开频道 → 始终内部
    if channel.type === OPEN_CHANNEL:
        return 'internal'

    // 规则 2：用户显式设置了 group_channel_category 偏好
    prefKey = getPreferenceKey('group_channel_category', channel.id)
    if myPreferences[prefKey]?.value === 'internal':
        return 'internal'

    // 规则 3：DM 频道 — 检查对方是否在当前团队
    if channel.type === DM_CHANNEL:
        otherUserId = getUserIdFromChannelName(currentUserId, channel.name)
        if !otherUserId:
            return 'external'
        if currentTeamMemberIds.has(otherUserId):
            return 'internal'
        else:
            return 'external'

    // 规则 4：GM/Private 频道 — 检查所有成员是否都在当前团队
    if channel.type === GM_CHANNEL or channel.type === PRIVATE_CHANNEL:
        memberIdsSet = profilesInChannel.get(channel.id)
        if !memberIdsSet or memberIdsSet is empty:
            return 'external'

        for memberId in memberIdsSet:
            if memberId === currentUserId:
                continue    // 跳过自己
            if !currentTeamMemberIds.has(memberId):
                return 'external'    // 有人不在当前团队 → 外部群

        return 'internal'

    // 兜底
    return 'external'
```

## makeGetClassifiedChannelIds 选择器

主选择器，返回 `ChannelClassification`（即 `ClassificationGroup[]`）。

### 子选择器列表

```
createSelector(
    'getClassifiedChannelIds',
    getAllChannels,                                          // Record<string, Channel>
    getCurrentUserId,                                        // string
    getCurrentChannelId,                                     // string
    (state) => { /* 构建 currentTeamMemberIds Set */ },     // Set<string>
    getUserIdsInChannels,                                    // Record<channelId, Set<userId>>
    getCurrentTeamId,                                        // string
    getCategoriesForCurrentTeam,                             // Category[]
    getCustomCategoryChannelIds,                             // Set<string>
    getPinnedChannelIds,                                     // Set<string>
    getMyPreferences,                                        // Record<string, any>
    resultFunction
)
```

### result 函数算法

```
1. 初始化 groupMap: { 'internal' → {channelIds:[]}, 'external' → {channelIds:[]} }

2. 收集待分类频道：
   - 遍历 categories（跳过 CUSTOM 类型）
   - 跳过已在 custom category 中的频道
   - 去重

3. 将 profilesInChannel 从 Record 转为 Map（O(1) 查找）

4. 逐个分类：
   - 跳过其他团队的频道（DM/GM 除外）
   - 跳过用户手动关闭的 DM/GM（检查 preference）
   - 调用 classifyChannel() 得到 groupId
   - 推入对应 group 的 channelIds

5. 每个 group 内部排序：公开优先 → 收藏次之

6. 返回 [internalGroup, externalGroup]
```

## 与旧版的差异

| 维度 | 旧版 | 新版 |
|------|------|------|
| 分类依据 | `employee_contacts` 表中的外部联系人 | 团队成员归属 |
| 数据来源 | `makeGetContactUserIdsByType()` → `{internal: Set, external: Set}` | `getMembersInTeam()` → `Set<string>` |
| DM 判断 | `contactUserIds.external.has(otherUserId)` | `!currentTeamMemberIds.has(otherUserId)` |
| GM 判断 | 遍历成员查 `contactUserIds.external.has()` | 遍历成员查 `!currentTeamMemberIds.has()` |
| 依赖的表 | `employee_contacts` | `TeamMembers` |
| 需要 import | `employee_contacts` selectors | `getMembersInTeam` from teams selectors |
